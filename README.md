## 1. Problem Statement

Large Language Models (LLMs) are increasingly used as autonomous agents that interact with other agents, but it is unclear whether they can sustain cooperation in repeated strategic interactions. This project studies the cooperative behaviour of small open LLMs (Qwen2.5-0.5B, 1.5B and 3B Instruct) in the 10-round **Iterated Prisoner's Dilemma (IPD)**.

The study answers four questions:

1. How do the LLMs behave against each other and against predefined strategies (Always Defect, Always Cooperate, Defect Once)?
2. Does cooperation change when the payoff unit (points / dollars / coins) or the action labels (J/F, X/Q, R/H) change? This is a prompt-robustness test.
3. Do a **forgiveness instruction** and **Social Chain-of-Thought (SCoT)** prompting increase cooperation against a "Defect Once" opponent?
4. How do the models compare overall on normalised score, defection rate and forgiveness?

## 2. Method and Data

The implementation follows the method of Akata et al. (2025), *"Playing repeated games with large language models"*, Nature Human Behaviour.

- **Game:** Prisoner's Dilemma with payoffs (C,C) = (8,8), (C,D) = (0,10), (D,C) = (10,0), (D,D) = (5,5), played for 10 rounds with full information.
- **Prompting:** the payoff matrix is converted to plain-text rules. The history of past rounds is appended to the prompt each round (in-context learning).
- **Action selection:** temperature 0. The chosen action is the option label with the highest next-token probability (no sampling).
- **SCoT:** the agent first predicts the opponent's move, then chooses its own move.
- **Metrics:** normalised score (score / 100), defection rate (%), forgiveness / joint cooperation in rounds 2-10 against Defect Once, and a position-bias diagnostic.

**Data:** there is no external dataset to download. All game trajectories are **generated by the notebook** and saved as CSV files in `results/`. The paper also describes the dataset of Akata et al. (2025) as a benchmark reference; it is not required to run this code.

**Models / checkpoints:** no model is trained or fine-tuned, so there are no custom checkpoints. Pretrained weights are downloaded automatically from Hugging Face on first run:

## 5. Reproducibility

- Random seed is fixed with `SEED = 42` for `random`, `numpy` and `torch`.
- Action selection is **deterministic** (argmax over next-token probabilities at temperature 0, no sampling), so repeated runs give the same results. The seed is set as a safeguard.
- Package versions are pinned in `requirements.txt`.
- Model outputs are cached within a run: an identical prompt always gives an identical answer.

## 6. Results Summary

Aggregate results over the configured PD experiments (`results/exp4_summary_table.csv`):

| Agent | Normalised score | Defection rate (%) | Forgiveness |
|---|---|---|---|
| Always Defect | 0.715 | 100.000 | 0.000 |
| Always Cooperate | 0.456 | 0.000 | 1.000 |
| Defect Once | 0.458 | 10.000 | 1.000 |
| Qwen-0.5B | 0.657 | 69.630 | 0.296 |
| Qwen-1.5B | 0.675 | 65.556 | 0.000 |
| Qwen-3B | 0.633 | 56.667 | 0.815 |
| Qwen-0.5B + SCoT | 0.671 | 72.593 | 0.222 |
| Qwen-1.5B + SCoT | 0.465 | 10.000 | 1.000 |
| Qwen-3B + SCoT | 0.652 | 56.667 | 0.444 |

**Key findings**

- Cooperation is **model-specific**. Qwen-3B has the lowest defection rate and a high forgiveness score among the baseline LLMs.
- Cooperation is **sensitive to prompt representation**. For example, Qwen-0.5B shows joint cooperation of 0.889 with J/F labels but 0.000 with X/Q labels.
- Neither intervention helps uniformly. SCoT raised joint cooperation for Qwen-1.5B (0.000 to 1.000) but lowered it for Qwen-0.5B (0.889 to 0.556). The forgiveness note alone changed little.
- Higher cooperation does not mean a higher score. Always Defect has the highest normalised score, and Qwen-1.5B + SCoT cooperates most but scores lower.

Limitations: only three small models, a 10-round game, selected prompt variants, and deterministic decoding (so no run-to-run variance is measured).
